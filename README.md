# Nasti WebGPU Demo
This is a demo project showcasing the capabilities of WebGPU using the Nasti framework. The project demonstrates various graphics rendering techniques and provides examples of how to utilize WebGPU for high-performance graphics applications.

Run the project by following the instructions below:

```bash
git clone https://github.com/zixiao-labs/nasti-wgpu-demo.git && cd nasti-wgpu-demo
pnpm install
pnpm dev
```
